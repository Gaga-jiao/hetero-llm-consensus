# 异构多厂商 LLM 的共识可靠吗？—— 基于 SimpleQA 的实测

> 3 家不同厂商的模型 × 30 道真实长尾难题 × 多次独立采样，
> 定量回答三个问题：**自报置信度还能不能用？换厂商有没有换来错误独立性？投票到底有没有增益？**

## 结论速览

在 30 道 SimpleQA 题目上（每题取各模型多次采样的多数答案参与裁决）：

| 裁决策略 | 准确率 |
|---|---|
| 最好单模型（DeepSeek） | 23% |
| 等权多数投票（3 家） | 23% |
| 自报置信度加权 | **13%** |
| 温度缩放校准后加权 | **13%** |
| 自一致性加权 | 23% |

五个发现：

1. **自报置信度严重过度自信**：全体 ECE = 0.537。模型说"我 0.96 确定"时，实际正确率只有 31.8%；说 0.85 时只有 15.8%。所有置信度区间都是**负偏差**。
2. **"异构"带来的独立性增益有限**：不同厂商两两错误相关性 **phi = +0.58**；而同一模型 10 次采样之间的相关性 **phi = +0.74**。换厂商只把相关性降低了 0.16。
3. **多数投票零增益**：23% vs 单模型最好 23%。在这类难任务上，投票没有跑赢最好的单个模型。
4. **置信度加权反而有害**：23% → 13%。原因是置信度与正确率**负相关** —— 智谱平均置信度最高（0.860）而准确率最低（13%），高置信度的错误答案会把共识带偏。
5. **自一致性是唯一单调有效的信号**：3 次采样一致率 0.20 → 正确率 6.2%；一致率 1.00 → 26.7%。但"一致地错"很普遍，所以它只能做参考，不足以翻盘。

## 对做多智能体系统的建议

1. **别默认"多模型投票 = 更可靠"** —— 在难任务上增益可能是 0，而成本是 N 倍。
2. **别用 prompt 自报的置信度做加权** —— 它可能把准确率砍掉近一半，还不如等权。
3. **"换厂商" ≠ "换视角"** —— 模型权重不同不代表错误独立；真正的独立性更可能来自**不同的信息源、工具、检索结果**，而不是不同的模型。
4. **如果一定要加权，用自一致性**（同题多次采样的一致率），它是可观测量；但把它当作"风险提示"，不要当作"正确性保证"。

## 实验设计

- **题目**：SimpleQA 随机子集 30 题（固定随机种子 `20260911`，可完全复现）。SimpleQA 是 OpenAI 开源的事实性基准（`openai/simple-evals`），专为测量"模型自信地答错"而设计，答案唯一、可自动判分。
- **模型**：3 家不同厂商 —— DeepSeek `deepseek-chat`、智谱 `glm-4-flash`、Groq `groq/compound-mini`
- **采样**：DeepSeek 每题 10 次、智谱 5 次、Groq 2 次，temperature 0.8，全部独立调用
- **提示词**：要求只输出答案 + 一行 `CONFIDENCE: <0-1>`（即 prompt-level confidence probing）
- **判分**：答案归一化后的字符串匹配（含数字/年份容错）；`data/raw.jsonl` 保留了模型的原始输出，可以换更严格的 LLM judge 重判

## 限制（诚实说明）

- **只有 3 家模型跑通**。原设计是 8 家：OpenRouter 免费池当日额度耗尽（`is_free_tier: true`，免费模型有每日上限），Kimi key 失效、阿里百炼账号欠费、火山接入点不对、MiniMax 套餐不支持、Gemini 渠道被拒。因此相关性统计的置信区间偏宽。
- **30 道题**规模偏小，判分用字符串匹配而非官方 LLM judge。
- 只有 3 家时"多数投票"的分辨率有限（本题上 2:1 即取胜）。

## 如何扩大实验

- **OpenRouter 充值 $10** → 免费模型额度从约 50 次/天 提升到 1000 次/天，可一次接入 5~8 家不同厂商
- 结清阿里云欠费 → 加回 Qwen 系列
- 题目扩到 100+ 道、采样提到 10 次，得出更紧的置信区间
- 加入**同源污染组**（所有模型读同一份材料）以测"共享输入"带来的相关性

## 附：可直接接进你系统的裁决器

`src/verdict.py` 把上面的结论固化成一个可直接调用的小组件：

- **不做置信度加权**（实测有害），跨来源取多数答案
- **用自一致性标记「哪些来源对此问题没把握」**，而不是拿它选答案
- **区分「多来源」与「独立来源」** —— 标记共享输入的来源，明确提示"这些来源之间不构成冗余"
- 低可信时给出的建议是**升级证据**（检索一手资料 / 跑工具验证 / 问人），而不是再加几个模型

用法：

```python
from verdict import Source, verdict

r = verdict([
    Source("deepseek", ["Michio Sugeno", "Michio Sugeno", "Sugeno"]),
    Source("zhipu",     ["Michio Sugeno", "Sugeno", "unknown"]),
    Source("shared-doc", ["Sugeno", "Sugeno"], independent=False),  # 与别人读了同一份材料
])
print(r["answer"], r["risk"], r["advice"])
```

实战表现（用本仓库的真实数据跑）：3 道题全部被标成 high/medium 风险。其中 Q01 三家模型各自自一致性高达
**0.9 / 1.0 / 0.67** 却**全都答错** —— 这正是"一致地错"。所以它的输出是**风险提示**，而非正确性保证；
它的价值在于告诉你"这题没把握，别再堆模型了，去拿证据"。
